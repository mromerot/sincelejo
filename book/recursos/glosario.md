---
title: Glosario
---

| Término | Uso en este libro |
|---|---|
| Amenaza | Intensidad y posibilidad de un fenómeno potencialmente dañino |
| Exposición | Personas, activos o funciones que pueden coincidir con el fenómeno |
| Vulnerabilidad | Condiciones que transforman intensidad en daño o interrupción |
| Riesgo | Impactos potenciales bajo condiciones y horizonte definidos |
| PAE | Valor esperado anual de pérdidas; requiere un modelo coherente de eventos y daños |
| Periodo de retorno | Recurrencia estadística, no calendario ni garantía de espera |
| Susceptibilidad | Propensión espacial; no necesariamente probabilidad temporal |
| Reanálisis | Reconstrucción meteorológica con modelo y observaciones; no estación local |
| Proyección | Futuro condicionado a escenarios y modelos |
| Pronóstico | Predicción para un horizonte y condiciones iniciales determinados |
| Sensibilidad | Cambio al modificar supuestos; puede no tener probabilidad o fecha |
| Riesgo compuesto | Interacción o coincidencia de factores que modifica impactos |
| Cascada | Propagación de una falla entre sistemas |
| Maladaptación | Intervención que aumenta vulnerabilidad o transfiere riesgos |
| CDD | Máxima racha seca definida por umbral y calendario |
| Z-P3 | Anomalía estandarizada de precipitación trimestral; no SPI/SPEI |
